> A native macOS App Store price tracker. Monitor app prices across multiple storefronts, view price history and all-time lows, and get notified when prices drop.

This repository is the standalone **AppDrop No Sandbox** edition. It uses no App Sandbox and no App Group, stores data in the user's Application Support directory, and does not require Full Disk Access.

## Features

- 🔍 **Multi-storefront tracking** — Track prices across 17 storefronts; each tracked item is tied to a specific storefront.
- 📈 **Price history chart** — Step-line chart with 3-, 6-, and 12-month or full-history ranges, exact hover prices, and counts of continuous all-time-low periods, powered by Swift Charts.
- 🏷️ **All-time low detection** — Automatically identifies and badges all-time low prices.
- 🔔 **Local notifications** — Sends a system notification when a price drops (main App and background Helper each request their own permission).
- 🔄 **Background checks** — Scheduled via SMAppService + launchd; the Helper runs, writes to the database, sends notifications, then exits — no persistent process.
- 📋 **Wishdrop format** — Import and export your tracking list as a `.wishdrop` file (JSON). An optional preset [`MacAppStore-Paid-Games.wishdrop`](MacAppStore-Paid-Games.wishdrop) is provided in the repository for users who want to manually import 85 certified Mac upfront-paid games.
- 🔗 **Two ways to add apps** — Paste an App Store link or search by keyword (Mac and iPhone·iPad catalogs supported).

## Getting Started

### Requirements

- macOS 14.0 or later
- Xcode 15 or later (with Command Line Tools)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

### Build & Run

```bash
# 1. Enter the standalone source directory
cd AppDrop-NoSandbox

# 2. Generate the Xcode project
xcodegen generate

# 3. Run unit tests (offline, no real prices required)
swift test --package-path SharedKit --scratch-path /private/tmp/AppDrop-NoSandbox-SwiftPM

# 4. Release build (Universal: arm64 + x86_64; no embedded profile)
xcodebuild -project AppDrop.xcodeproj -scheme AppDrop -configuration Release \
  -derivedDataPath /private/tmp/AppDrop-NoSandbox-DD \
  ARCHS='arm64 x86_64' ONLY_ACTIVE_ARCH=NO CODE_SIGNING_ALLOWED=NO build

# 5. Sign with the local Apple Development identity and install
Scripts/make-signed-build.sh \
  "/private/tmp/AppDrop-NoSandbox-DD/Build/Products/Release/AppDrop No Sandbox.app" \
  "/Applications/AppDrop No Sandbox.app"

# 6. Produce ZIP, DMG, and SHA-256 files
Scripts/package-no-sandbox.sh "/Applications/AppDrop No Sandbox.app" 1.0.5
```

For detailed instructions including signing, installation, and troubleshooting, see [Documentation/build-and-run.md](Documentation/build-and-run.md).

### Permissions and Distribution

- Neither the app nor the Helper needs Full Disk Access.
- Notification and background login-item permissions remain standard macOS user approvals.
- This build is Apple Development signed and not notarized. On another Mac, use right-click → Open for the first launch.

A Developer ID signature plus Apple notarization is required to remove that first-launch Gatekeeper step.

## How Background Checks Work

- The main app registers `AppDropHelper` via `SMAppService.agent(plistName: "com.appdrop.nosandbox.helper.plist")`; the plist is embedded at `Contents/Library/LaunchAgents/`.
- The Helper runs with `--scheduled` by default: it skips if fewer than 20 hours have passed since the last attempt. Use `--run-now` to force an immediate run. After writing to the database and sending notifications, it exits — no persistent polling.
- `StartInterval = 86400` is a best-effort target; the Helper may run late after sleep or shutdown, and will catch up via the overdue-check logic.

See [Documentation/background-helper.md](Documentation/background-helper.md) for full details.

## Notification Permissions

macOS grants notification permissions per process identity:

- **AppDrop No Sandbox (main app)** — Requested during onboarding. Notifications from manual refreshes use this permission.
- **AppDrop No Sandbox Helper (background)** — Requested independently on first run. Notifications from launchd-scheduled checks use this permission. If denied, enable it in **System Settings → Notifications → AppDrop No Sandbox Helper**.

## Wishdrop Format

Your tracking list can be exported as a `.wishdrop` file (JSON) to share across devices or with other users. See [Documentation/wishdrop-format.md](Documentation/wishdrop-format.md) for the schema.

## Local Shared Database

- Bundle ID: `com.appdrop.nosandbox`; Helper: `com.appdrop.nosandbox.helper`
- Database path: `~/Library/Application Support/AppDropNoSandbox/AppDrop.store`
- Both the main app and the Helper use identical `ModelConfiguration`; failure to resolve the writable local directory is reported instead of falling back to Group Containers.
- A real write probe validates the shared storage directory at startup.
- Cross-process writes are serialized with an `flock` advisory lock; price records carry an idempotent `notifiedAt` flag to prevent duplicate notifications.

## Search Notes

"Add App → Search" offers **Mac** and **iPhone·iPad** catalog options (Mac is the default):

- Mac catalog: uses `entity=macSoftware` with additional `kind` filtering.
- iPhone·iPad catalog: uses `entity=software`.
- Apple's search index has gaps (some recently released Mac titles are missing). For those apps, add them via their App Store link instead.

## Known Limitations

| Limitation | Details |
|------------|---------|
| Code signing | Apple Development signed; not Developer ID signed or notarized — other Macs require right-click → Open on first launch |
| Background schedule accuracy | `StartInterval` is not a strict guarantee; the Helper may be delayed if the Mac is asleep or shut down |
| Currency conversion | No exchange-rate conversion; prices across different storefronts are not compared or merged |
| Discount definition | "Price drop" means the new price is lower than the previous recorded price — not an official App Store promotional discount |
| All-time low detection | Based on locally recorded observations: a price counts as a low only when it equals the recorded minimum and a higher price was observed before. A first-time baseline never counts; App Store's official price history is not available |
| Data migration | Tracking data lives in local Application Support; use export/import Wishdrop to migrate between machines |
